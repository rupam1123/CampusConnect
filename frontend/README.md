# Frontend

React UI for CampusConnect by Rupam. See the root README for the verified full-stack setup, hosted sign-in and submission links.

- `npm run dev`: Vite development server with the backend proxy.
- `npm run lint`: React and JavaScript checks.
- `npm run build`: standalone frontend build.

For the ChatGPT-hosted application, build from the repository root so the frontend and backend are packaged together.
